# LCMS Fresh Start — Expanded Workflow

A development MVP for an AI-assisted government Legal Case Management System.

## Stack
- FastAPI + SQLAlchemy + PostgreSQL
- PyMuPDF PDF text extraction and source-page rendering
- OpenAI-compatible LLM endpoint (Groq-compatible configuration)
- React + Vite
- DOCX/PDF notesheet export

## Run
1. Extract the ZIP.
2. Copy `.env.example` to `.env`.
3. Add your Groq API key to `LLM_API_KEY`.
4. Run `docker compose up --build`.
5. Open frontend at http://localhost:5173 and API docs at http://localhost:8000/docs.

## Features in this build
- Case create, edit, list and delete
- Multi-PDF upload (up to 30 files per batch), individual and bulk processing
- PDF text extraction, page/chunk storage and document deletion
- Case-scoped retrieval across all processed PDFs
- LLM-assisted paragraph-level analysis with multiple citations per paragraph
- Quote validation against the cited PDF and automatic extraction of all matching PDF rectangles
- Multiple highlight segments per citation, including repeated passages
- Click citation to open its source page image with coordinate-based visual highlights
- Editable notesheet: generate, load, save, add/remove/reorder sections
- DOCX and PDF notesheet export
- Case metadata editing

## Important limits
- Scanned/image-only PDFs require OCR; this version detects no selectable text and cannot produce reliable quote highlights for those pages.
- Analysis quality depends on the configured model and source text. It is not a legal opinion.
- The model only gets a bounded set of source chunks (MAX_CONTEXT_CHUNKS). Large cases need a proper hybrid retrieval/indexing pipeline.
- PDF highlight coordinates are generated by PyMuPDF, not by the LLM. If the quote cannot be found exactly, the citation remains but no overlay is shown.
- This is not production-ready: add Alembic migrations, authentication/RBAC, audit trails, antivirus scanning, file encryption, backups, OCR, test coverage, rate limiting and deployment hardening before official use.

See `docs/SETUP.md` for setup, API endpoints and next engineering steps.
